# 🇮🇳 Spoken Kannada – Day 23
## Likes & Dislikes (ಇಷ್ಟಗಳು ಮತ್ತು ಇಷ್ಟವಿಲ್ಲದವುಗಳು)

**Level:** Beginner  
**Duration:** 15–20 minutes  
**Course:** Spoken Kannada for Beginners

---

## 🎯 Today's Goal

By the end of this lesson, you should be able to:

1. Say what you like and dislike.
2. Ask someone about their preferences.
3. Express how much you like something.
4. Talk about food, hobbies and activities you enjoy.

## 1. Essential Vocabulary

| English | Kannada Pronunciation |
|---|---|
| Like | Ishta |
| Dislike | Ishta illa |
| Very much | Tumba |
| A little | Swalpa |

| Watching | Noduva |

## 2. Expressing What You Like

The most useful sentence pattern is:

**Nanage + Thing/Activity + ishta.**

It means "I like..."

| English | Kannada Pronunciation |
|---|---|
| I like coffee. | Nanage kaafi ishta. |
| I like tea. | Nanage chaha ishta. |
| I like music. | Nanage sangeetha ishta. |
| I like movies. | Nanage cinema ishta. |
| I like travelling. | Nanage prayaana maaduvudu ishta. |
| I like swimming. | Nanage eejuvudu ishta. |
| I like walking. | Nanage nadeyuvudu ishta. |
| I like playing cricket. | Nanage cricket aaduvudu ishta. |

## 3. Expressing What You Don't Like

Use this pattern:

**Nanage + Thing/Activity + ishta illa.**

It means "I don't like..."

| English | Kannada Pronunciation |
|---|---|
| I don't like coffee. | Nanage kaafi ishta illa. |
| I don't like tea. | Nanage chaha ishta illa. |
| I don't like spicy food. | Nanage khaara oota ishta illa. |
| I don't like movies. | Nanage cinema ishta illa. |
| I don't like travelling. | Nanage prayaana maaduvudu ishta illa. |
| I don't like swimming. | Nanage eejuvudu ishta illa. |

## 4. Expressing How Much You Like Something

You can also express the degree of your liking.

| English | Kannada Pronunciation |
|---|---|
| I like it very much. | Nanage adu tumba ishta. |
| I like it a little. | Nanage adu swalpa ishta. |
| I really like coffee. | Nanage kaafi tumba ishta. |
| I like this. | Nanage idu ishta. |
| I don't like that. | Nanage adu ishta illa. |
| I like this food very much. | Nanage ee oota tumba ishta. |

## 5. Asking Others About Their Preferences

Use **Nimge ... ishta na?** to ask someone politely whether they like something.

| English | Kannada Pronunciation |
|---|---|
| Do you like coffee? | Nimge kaafi ishta na? |
| Do you like tea? | Nimge chaha ishta na? |
| Do you like music? | Nimge sangeetha ishta na? |
| Do you like cricket? | Nimge cricket ishta na? |
| Do you like travelling? | Nimge prayaana maaduvudu ishta na? |
| What do you like? | Nimge enu ishta? |
| Which food do you like? | Nimge yaava oota ishta? |

### Common Responses

- Howdu, nanage ishta. – Yes, I like it.
- Howdu, tumba ishta. – Yes, I like it very much.
- Illa, nanage ishta illa. – No, I don't like it.
- Nanage swalpa ishta. – I like it a little.

## 6. Mini Conversation – Talking About Hobbies

**Person A:** Nimge cricket ishta na?  
*Do you like cricket?*

**Person B:** Howdu, nanage cricket tumba ishta.  
*Yes, I like cricket very much.*

**Person A:** Nimge swimming ishta na?  
*Do you like swimming?*

**Person B:** Howdu, nanage swimming ishta.  
*Yes, I like swimming.*

**Person A:** Nimge cinema ishta na?  
*Do you like movies?*

**Person B:** Illa, nanage cinema ashtu ishta illa.  
*No, I don't like movies that much.*

**Person A:** Nimge enu tumba ishta?  
*What do you like very much?*

**Person B:** Nanage music tumba ishta.  
*I like music very much.*

## 7. Quick Quiz

### Section A – Fill in the Blanks

1. Nanage coffee ______. (I like coffee.)
2. Nanage khaara oota ______. (I don't like spicy food.)
3. Nimge cricket ______? (Do you like cricket?)
4. Nanage adu ______ ishta. (I like that very much.)
5. Nimge ______ ishta? (What do you like?)

### Section B – Translate into Kannada

Use English letters (Roman transliteration) only.

6. I like music.
7. I don't like tea.
8. Do you like swimming?
9. I like travelling very much.
10. What do you like?

## 8. 🗣️ Today's Speaking Challenge

Talk about your personal preferences using these sentence starters:

**Things I like:**
- Nanage ______ ishta.
- Nanage ______ tumba ishta.

**Things I don't like:**
- Nanage ______ ishta illa.

**Questions to ask your family:**
- Nimge enu ishta?
- Nimge ______ ishta na?

Try using these topics:

- Food and drinks
- Sports and games
- Movies and music
- Travelling
- Walking and swimming
- Reading and cooking

Try to have a conversation with at least two family members.
